# 素材标准与打分表（2026-10-01 经 taevas 确认）

适用范围：本项目全部游戏素材（猫 sprite、UI、图标、音效等）的搜集、评分与选用。

## 美术主旨（一票否决门，先于打分）

**本游戏核心风格 = 卡通 Q 版**：chibi 头身比、圆润饱满、色彩明快、休闲可爱。
任何素材先过风格门再谈分数：写实风、硬核像素、暗黑哥特、拟真照片风**一律直接放弃**（无论其他维度多高）。
音效同理：音色偏卡通轻快（拨弦/木琴/短促 pop），拒绝重金属、拟真采样堆砌。

## 打分表（10 分制，逐维度打分，合计保留一位小数）

| 维度 | 满分 | 评分要点 |
|---|---|---|
| 造型可爱度 | 3.0 | Q 版比例（头大身小）、大眼圆润、表情讨喜、轮廓协调。3=一眼可爱；2=耐看但平淡；1=一般；0=丑 |
| 线条与上色质量 | 2.0 | 描边均匀细致（或无描边扁平干净）、无毛边锯齿、上色不分层不脏 |
| 配色百搭度 | 2.0 | 柔和明快；放在 24 色调色板任一色块上不冲突不脏；灰白/奶/橘百搭色优先 |
| 棋子可读性 | 1.5 | 缩到 48px 仍清晰、剪影辨识度高（棋子最终显示 40~60px） |
| 状态覆盖 | 1.0 | 开心/难过/Hurt/Dead/眨眼 idle 等差分。1.0=全覆盖；0.5=2~3 态；0=单态 |
| 技术规格 | 0.5 | 透明底 PNG、本体 ≥128px、逐帧尺寸对齐一致 |

## 选用门槛

- **≥9.0 分：选用。**
- 8.0~8.9：备选，仅在找满来源仍无 ≥9 时，报用户确认后可用。
- <8.0：放弃。
- **宁缺毋滥**：空手而归强过收低分图。

## 搜集策略（找素材阶段就往高分找）

1. **先挑来源再挑图**：优先知名画师/工作室、精选合集、热门下载榜；关键词带 cute / kawaii / chibi。
2. **预筛**：先看页面缩略图，主观觉得可能 ≥9 才下载，不撒网。
3. **逐图打分**：agent（或人）必须用 Read 亲眼看每一张实际图片打分，禁止按文件名猜。
4. **校准锚点**：第一轮三套候选评分 A 灰猫 7.0 / B 橘胖猫 5.0 / C 小猫 4.0——它们都未达选用线，新素材必须明显好于 A。
